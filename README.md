# EQLogMonitor
EQ Log Monitor tool

To run, place EQLogMonitor.exe into a directory and run it.
A .dat file will be created to store the values that you enter into the fields.

Uses a third party phone app called "ntfy" for push notifications.
To use this feature, install the app on your phone, create a "topic", and enter
the topic name into the NOTIFY field in EQLogMonitor.exe.
For more info about the ntfy app visit: https://ntfy.sh/
